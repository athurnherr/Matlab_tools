# Matlab tools written by A.M. Thurnherr

## Notes

- The tools in this collection are mostly undocumented. The most
generally useful one is loadANTS.m, which loads data files in the ANTS
format into Matlab. The ANTS format is used by the LADCP_w vertical
velocity processing software and by the ADCP tools, both maintained by
the same author.

- To find out which version you have installed, run "make" in install
directory.

- While there is no official support for this software feel free to
contact the author with questions or requests. 

- Most of the source files use a hard tab of 4 spaces, i.e. they can be
viewed correctly, e.g. with "less -x4".
